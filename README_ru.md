## Почему InkForum?

| | |
|---|---|
| **Запуск за считаные минуты** | Установщик в одну строку подготовит Docker, получит бесплатный HTTPS-сертификат для вашего домена и передаст вас удобному мастеру настройки. |
| **Быстро даже на недорогом железе** | Один процесс и SQLite по умолчанию — без Redis, без поискового сервера и без отдельного сервера базы данных. VPS с 1 ГБ RAM более чем достаточно. |
| **Полный контроль без кода** | Темы, цвета, меню, главная страница, права доступа, шаблоны писем, плагины… всё настраивается в панели администратора. |
| **Обновление в один клик** | Новые версии появляются в панели вместе с описанием изменений. Перед обновлением создаётся резервная копия, а если что-то пойдёт не так, предыдущая версия восстанавливается автоматически. |
| **Безопасность по умолчанию** | Встроенный межсетевой экран для веб-приложений (WAF), двухфакторная аутентификация, повторная аутентификация для действий администратора, строгая Content Security Policy. |
| **Многоязычность** | Английский, турецкий, немецкий, китайский, испанский, французский, русский и португальский — каждый участник выбирает свой язык. |

## 🚀 Быстрый старт

На Ubuntu, Debian, Rocky, Alma или любом Linux-сервере, где можно запустить Docker:

```bash
curl -fsSL https://raw.githubusercontent.com/vokartz/inkforum/main/install.sh | sudo bash
```

Скрипт:

1. устанавливает Docker, если его нет (предварительно спросив вас),
2. создаёт `/opt/inkforum` и файл `.env` с надёжными случайными секретами,
3. включает **автоматический HTTPS** (Let's Encrypt через Caddy), если вы укажете домен,
4. запускает InkForum и выводит ваш **адрес и код установки**.

Откройте `https://your-domain.com/install` в браузере. Мастер проверит сервер и спросит название форума,
тему, учётную запись администратора, режим регистрации, плагины и (по желанию) настройки почты. Вот и всё.

> **Зачем нужен код установки?** Он не позволяет посторонним перехватить только что установленный сервер, доступный из интернета.
> Код выводится только в журнал сервера: `docker compose -f /opt/inkforum/docker-compose.yml logs inkforum | grep "Kurulum kodu"`

### Ручная установка (Docker Compose)

```bash
mkdir -p /opt/inkforum && cd /opt/inkforum
curl -fsSLO https://raw.githubusercontent.com/vokartz/inkforum/main/docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/vokartz/inkforum/main/.env.example -o .env
# fill in APP_URL, APP_SECRET and UPDATER_TOKEN in .env
docker compose up -d
```

### Coolify, Dokploy, Portainer

Добавьте `docker-compose.yml` прямо в свою платформу и задайте `APP_URL`, `APP_SECRET` (не менее 32 символов) и
`UPDATER_TOKEN` (не менее 16 символов). Если у платформы есть собственный обратный прокси, оставьте `TRUST_PROXY=uniquelocal`
и не включайте профиль `https` (Caddy).

### Системные требования

| | Минимум | Рекомендуется |
|---|---|---|
| Процессор | 1 vCPU (amd64 или arm64) | 2 vCPU |
| Память | 1 ГБ | 2 ГБ |
| Диск | 5 ГБ | 20 ГБ + загруженные файлы |
| ПО | Docker 24+ с плагином Compose | — |

Не можете использовать Docker (cPanel/Passenger, Plesk, чистый Node.js)? В каждом релизе есть и **серверный пакет** — см.
[Установка без Docker](#установка-без-docker).

## 🔄 Обновления

InkForum отслеживает [релизы](https://github.com/vokartz/inkforum/releases) этого репозитория.

- **Админка → Обновления** показывает вашу версию, последнюю версию и её **список изменений**.
- **Обновить сейчас**: резервная копия базы данных → загрузка нового образа → перезапуск с проверкой работоспособности → **автоматический откат**, если
  новая версия не запустилась. Ход обновления отображается в реальном времени.
- **Автоматические обновления**: выключены, только исправления (1.2.x), исправления + новые функции (1.x) или все обновления — в выбранный вами ночной час.
  Администраторы получают уведомление о выходе новой версии.
- Каналы **Stable / Beta**.

Предпочитаете командную строку?

```bash
cd /opt/inkforum && docker compose pull && docker compose up -d
```

Изменения базы данных применяются автоматически при запуске.

## 💾 Резервные копии и восстановление

- **Админка → Обслуживание и резервные копии**: снимок базы данных, переносимый **SQL-дамп** или **полная резервная копия** (база данных + загруженные файлы).
- Ежедневное автоматическое резервное копирование в выбранный вами час; хранятся N последних копий. Копия также создаётся перед каждым обновлением и каждым восстановлением.
- **Загрузка и восстановление**: загрузите резервную копию (в том числе с другого сервера), введите `GERİ YÜKLE` для подтверждения — и InkForum восстановит её
  при перезапуске. Текущее состояние предварительно сохраняется, так что вернуться назад можно всегда.
- Всё (база данных, загрузки, резервные копии) хранится в Docker-томе `inkforum-storage`:

```bash
docker run --rm -v inkforum_inkforum-storage:/data -v "$PWD":/backup alpine tar czf /backup/inkforum-storage.tgz -C /data .
```

## 🚚 Импорт с другого форума

Переезжаете с **SMF**, **phpBB**, **Invision Community (IPS)** или **MyBB**? **Админка → Импорт** перенесёт из дампа базы данных участников, группы

## ⚙️ Конфигурация

Все настройки форума находятся в панели администратора. Файл `.env` описывает только инфраструктуру:

| Переменная | Описание |
|---|---|
| `APP_URL` | Полный адрес сайта (`https://forum.example.com`) |
| `APP_SECRET` | Ключ сессий и шифрования (32+ символа; при его смене все пользователи будут разлогинены) |
| `UPDATER_TOKEN` | Общий ключ с контейнером обновлений |
| `DOMAIN`, `COMPOSE_PROFILES=https` | Автоматический HTTPS через Caddy |
| `DB_DRIVER`, `DATABASE_URL` | Использовать PostgreSQL (добавьте `postgres` в `COMPOSE_PROFILES`) |
| `TRUST_PROXY` | Реальные IP клиентов за обратным прокси (рекомендуется `uniquelocal`) |
| `INKFORUM_PORT`, `INKFORUM_BIND` | Публикуемый порт и адрес привязки |
| `UPDATES_DISABLED` | Отключить проверку обновлений на серверах без интернета |
| `WAF_DISABLED` | Аварийный выключатель файрвола |

## Установка без Docker

Каждый релиз содержит `inkforum-<version>-linux-x64.tar.gz` (со всеми зависимостями) и `inkforum-<version>.tar.gz`.
Требуется Node.js 22.13 или новее.

```bash
curl -fsSLO https://github.com/vokartz/inkforum/releases/latest/download/inkforum-<version>-linux-x64.tar.gz
tar xzf inkforum-*-linux-x64.tar.gz && cd inkforum
cp .env.example .env   # fill in APP_URL and APP_SECRET
NODE_ENV=production node --env-file=.env server.mjs
```

Запускайте его через systemd, PM2 или Passenger. При обновлении из панели пакет скачивается, проверяется по SHA-256, устанавливается,
после чего процесс перезапускается (перезапуск должен выполнять ваш менеджер процессов). Пример юнита systemd:

```ini
[Unit]
Description=InkForum
After=network.target

[Service]
WorkingDirectory=/opt/inkforum
Environment=NODE_ENV=production
ExecStart=/usr/bin/node --env-file=.env server.mjs
Restart=always
User=inkforum

[Install]
WantedBy=multi-user.target
```

## ❓ Частые вопросы

**Какую базу данных выбрать?**
Для большинства сообществ достаточно SQLite — она требует минимального обслуживания. PostgreSQL поддерживается для очень крупных
сообществ или если вы предпочитаете управляемую базу данных.

**У моего сервера нет доступа в интернет — как обновляться?**
Установите `UPDATES_DISABLED=true`, загрузите новый образ вручную и выполните `docker compose up -d`.

**Файрвол заблокировал мне доступ.**
Добавьте `WAF_DISABLED=true` в `.env`, выполните `docker compose up -d`, а затем исправьте настройки в панели.

**Я забыл пароль администратора.**
Воспользуйтесь ссылкой «Забыли пароль?» на странице входа. Если почта не настроена, ссылка записывается в `storage/mail`:
`docker compose exec inkforum ls /app/storage/mail`
